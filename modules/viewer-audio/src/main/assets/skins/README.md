# Winamp skins

Infinimedia owns these four original skin archives. Folder's former `Winamp/` and `themes/mediaplayer/` copies were byte-identical and have been consolidated here. Archives are unchanged, preserving embedded artwork, metadata and author readmes. See each Classified/Bento archive's readme for its original attribution. The inherited base-2.91 archive contains no separate license text; no new license is asserted for third-party artwork.

`MediaAssetOwnershipTest` parses every archive and fails if it is missing. Shared UI parser tests use synthetic fixtures and do not depend on application assets.
