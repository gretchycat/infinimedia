# Optional Winamp skin fixtures

These four original skin archives are compatibility fixtures only, outside Android production assets. They are not copied into the APK or offered as bundled choices. Infinimedia Default is the sole packaged skin. Infinimedia owns these archives. Folder's former `Winamp/` and `themes/mediaplayer/` copies were byte-identical and have been consolidated here. Archives are unchanged, preserving embedded artwork, metadata and author readmes. See each Classified/Bento archive's readme for its original attribution. The inherited base-2.91 archive contains no separate license text; no new license is asserted for third-party artwork.

`MediaAssetOwnershipTest` parses every archive and fails if it is missing. Shared UI parser tests use synthetic fixtures and do not depend on application assets.
